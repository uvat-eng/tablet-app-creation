# Сборка приложения «Малышенское» для App Store

Проект полностью подготовлен. Осталось собрать его на компьютере Mac —
Apple разрешает выпуск приложений только оттуда.

## Что уже сделано

- iOS-проект создан и настроен
- Название: **Малышенское**, идентификатор: `ru.malyshenskoe.crm`
- Версия 6.7, номер сборки 58
- Фирменная иконка и заставка
- Русские пояснения для геопозиции, камеры и фото
- Манифест приватности (обязателен с 2024 года)
- Кнопка установки APK скрыта на iPhone (иначе Apple отклоняет)
- Минимальная версия iOS 14

## Что нужно от вас

1. **Компьютер Mac** — свой, у знакомых или в аренду (облачные Mac от ~1000 ₽/сутки)
2. **Apple Developer Program** — 99 долларов в год, developer.apple.com/programs
3. **Xcode** — бесплатно в Mac App Store

## Порядок сборки на Mac

Скачайте код проекта: в редакторе **Скачать → Скачать код**.
Дальше в приложении «Терминал»:

```bash
cd путь-к-проекту
npm install
npm run build
npx cap sync ios
cd ios/App && pod install
open App.xcworkspace
```

Откроется Xcode. Далее:

1. Слева выберите проект **App** → вкладка **Signing & Capabilities**
2. Поставьте галочку **Automatically manage signing**
3. В поле **Team** выберите свою команду разработчика
4. Сверху вместо симулятора выберите **Any iOS Device (arm64)**
5. Меню **Product → Archive** — сборка займёт несколько минут
6. В открывшемся окне **Distribute App → App Store Connect → Upload**

## После загрузки

Зайдите на appstoreconnect.apple.com и заполните карточку:

- Название: Малышенское
- Категория: Бизнес (или Утилиты)
- Скриншоты с iPhone — минимум 3 штуки
- Описание, ключевые слова
- Ссылка на политику конфиденциальности — обязательна
- Возрастной рейтинг: 17+ (тематика охоты)

В разделе **App Privacy** укажите собираемые данные: имя, телефон,
геопозиция, фото — всё только для работы приложения, без рекламы
и без отслеживания.

## Важно для проверки Apple

Приложение закрыто логином, поэтому в поле **App Review Information →
Notes** обязательно впишите тестовый доступ, иначе проверяющий не
пройдёт дальше экрана входа:

```
Логин: appreview
Пароль: AppReview2026
Тип входа: Сотрудник хозяйства
```

Проверка обычно занимает от суток до трёх дней.

## Обновления в будущем

При каждой новой версии поднимайте два числа в Xcode:
**Version** (например 6.8) и **Build** (59, 60 и так далее) —
Apple не принимает повторяющийся номер сборки.
